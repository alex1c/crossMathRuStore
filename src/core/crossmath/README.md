# CrossMath core (`src/core/crossmath`)

Pure TypeScript mathematical engine for CrossMath puzzles.

## Rules

- No React Native / Expo imports.
- Runnable under Jest / Node for large automated test suites.
- Generator, solver, uniqueness, and difficulty logic belong here (Phase 1+).

## Phase 0

Only type placeholders and a stub `createCrossMathEngine()` are present.
Do not implement algorithms in this phase.
